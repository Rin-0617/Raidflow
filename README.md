# RaidFlow

RaidFlow は、レイド攻略向けのタイムラインメモ/軽減計画 Dalamud プラグインです。

現在のMVP:

- 手動タイムライン編集
- タイムライン一括削除
- PTスロット/ジョブ設定
- ジョブ別の軽減スキル一覧
- コンテンツLvに応じた一部スキル名/アイコンの差し替え
- タイムラインイベントへの軽減割り当て
- 効果時間/リキャスト警告
- ギミックメモのオーバーレイ表示
- 選択スロットの軽減強調表示
- 個人表示中でもPT軽減を表示
- 戦闘開始での自動スタート
- ワイプ検知での自動リセット
- FFLogs URLから敵castタイムラインの下書き生成
- 個人スロットの .radflow エクスポート
- 全体プランの .radflow エクスポート
- 他メンバーの .radflow を現在のプランへ合成

次にやること:

- 攻略中に現在時刻を記録するマーカーホットキー
