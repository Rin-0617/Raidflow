# RaidFlow

FFXIV Dalamud向けのレイド攻略支援プラグインです。

タイムラインメモ、軽減計画、オーバーレイ表示、FFLogsからのタイムライン下書き生成を1つの画面で扱えます。
固定メンバーごとの軽減案を `.radflow` ファイルとしてエクスポートし、他メンバーのファイルを読み込んで固定用の軽減表へ合成できます。

## 主な機能

- 手動タイムライン編集
- タイムライン一括削除
- PTスロット/ジョブ設定
- コンテンツLvに応じたスキル名/アイコン/リキャストの切り替え
- タイムラインイベントへの軽減割り当て
- 効果時間/リキャスト警告
- ギミックメモのオーバーレイ表示
- 選択スロットの軽減強調表示
- 個人表示中のPT軽減表示
- 戦闘開始での自動スタート
- ワイプ検知での自動リセット
- 同梱プリセットTLの読み込み
- FFLogs URLから敵castタイムラインの下書き生成
- 個人スロットの `.radflow` エクスポート
- 全体プランの `.radflow` エクスポート
- 他メンバーの `.radflow` を現在のプランへ合成

## 導入

Dalamud設定の試験的機能からCustom Plugin Repositoriesへ上記URLを追加してください。
リリース版はGitHub Releasesのzipを参照します。

## 初回設定

1. `/raidflow` でRaidFlowを開きます。
2. コンテンツ名、版、コンテンツLvを設定します。
3. PT設定タブで各スロットのジョブを設定します。
4. プリセットTLを読み込むか、タイムラインを手動作成、またはFFLogs読込タブから下書きを生成します。
5. タイムラインの行を選択し、スキルアイコンを押して軽減を割り当てます。
6. オーバーレイタブで表示内容、自動スタート、自動リセットを調整します。
7. インポート/エクスポートタブから `.radflow` ファイルを保存、または他メンバーの `.radflow` を読み込みます。

## プリセットTL

コンテンツ欄の近くにあるプリセットTLから、同梱済みの日本語タイムラインを読み込めます。

プリセットTLはタイムラインイベントのみを置き換えます。PT設定は維持され、軽減割り当ては空の状態から作成できます。

同梱コンテンツ:

- アルカディア零式：ライトヘビー級1層
- アルカディア零式：ライトヘビー級2層
- アルカディア零式：ライトヘビー級3層
- アルカディア零式：ライトヘビー級4層 前半
- アルカディア零式：ライトヘビー級4層 後半
- 絶バハムート討滅戦
- 絶アルテマウェポン破壊作戦
- 絶アレキサンダー討滅戦
- 絶竜詩戦争
- 絶オメガ検証戦
- 絶もうひとつの未来
- 絶妖星乱舞

## FFLogs読込

`ja.fflogs.com` / `www.fflogs.com` の公開レポートURLに対応しています。

URL内に `fight=` が含まれている場合は、そのfightを優先して読み込みます。Fight IDが未指定の場合は、レポート内の最後のボス戦を使用します。

FFLogs APIを使うため、Access Token、またはClient ID / Client Secretの入力が必要です。

プリセットがないコンテンツや、自分で取得したログから下書きを作りたい場合に使用します。

## .radflowファイル

`.radflow` はRaidFlowのインポート/エクスポート用ファイルです。

- 全体プラン: タイムライン、PT設定、全員分の軽減を含みます。
- 個人プラン: 選択スロットのプレイヤー名、ジョブ、担当軽減を含みます。

固定で使う場合は、各メンバーが個人プランを保存し、代表者がそれらを読み込むことで軽減表を合成できます。

## コマンド

```text
/raidflow
```

サブコマンド:

- `/raidflow overlay`
- `/raidflow start`
- `/raidflow pause`
- `/raidflow resume`
- `/raidflow reset`
- `/raidflow autosync`

## 注意

このプラグインは開発中です。

FFLogs APIやDalamud API、ゲームデータの変更により、一部の読み込み、名前解決、アイコン表示が動作しなくなる場合があります。
ワイプ検知は戦闘終了やコンテンツ遷移の状態をもとにした補助機能のため、カットシーンを含むコンテンツでは意図しないタイミングでリセットされる場合があります。
